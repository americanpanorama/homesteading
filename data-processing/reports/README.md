# Reports

This directory holds generated audit output and other derived review artifacts.

Current contents:

- `published-data-audit.md`: human-readable comparison of published `yearData` and `timelineData`
- `published-data-audit.json`: machine-readable version of the same audit
- `published-office-audit.md`: office-level comparison of published `yearData` and state office timeline files
- `published-office-audit.json`: machine-readable version of the office-level audit
- `mismatch-trace-notes.md`: targeted notes for specific mismatch cases such as Idaho and Oklahoma
- `trial-regeneration-report.md`: results from a safe temporary rerun of the current top-level generators
- `regenerated-data-audit.md`: state-level audit of regenerated temporary outputs
- `regenerated-office-audit.md`: office-level audit of regenerated temporary outputs
- `regeneration-comparison.md`: published vs regenerated mismatch summary

The audit files are generated by:

- [`../scripts/diagnostics/auditPublishedDataConsistency.mjs`](../scripts/diagnostics/auditPublishedDataConsistency.mjs)
- [`../scripts/diagnostics/auditPublishedOfficeTimelineConsistency.mjs`](../scripts/diagnostics/auditPublishedOfficeTimelineConsistency.mjs)

The trial-regeneration report is based on:

- [`../scripts/diagnostics/runTrialRegeneration.mjs`](../scripts/diagnostics/runTrialRegeneration.mjs)

The broader comparison outputs are based on:

- [`../scripts/diagnostics/runRegenerationComparison.mjs`](../scripts/diagnostics/runRegenerationComparison.mjs)

The route-range audit is based on:

- [`../scripts/diagnostics/auditPlacesDateRanges.mjs`](../scripts/diagnostics/auditPlacesDateRanges.mjs)
